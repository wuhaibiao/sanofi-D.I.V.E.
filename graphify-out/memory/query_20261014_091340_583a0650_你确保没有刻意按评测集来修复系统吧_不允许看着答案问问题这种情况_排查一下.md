## 发现与处理

1. 旧写入/答题进程读取同一个含答案的样本，且构造了未使用的GoldLabel。日志显示答案未传入模型，但隔离边界不够强。新运行改为三个字段白名单文件：写入只有历史；答题只有原题和日期/来源标识；评分才使用答案。可信制样阶段机械分离数据、不调用模型、不按答案筛题。缺失文件或出现额外答案字段即拒绝运行，不回退到完整样本。
2. 报告生成脚本中有一处参考答案文字常量，并有逐题诊断常量。它们仅用于离线报告，没有进入抽取或答题调用；现移至结果数据文件。修复后原报告文字保持一致，没有更改分数、参考答案或逐题记录。
3. 旧调用按题号复用OpenCode会话头，回答与评分之间没有分阶段隔离。服务方说明该头用于路由及提示缓存，不能据此认定自动携带历史；本机Responses适配器发送完整input、store=false，冻结配置没有previous_response_id或conversation链接。新评测脚本仍主动按运行与阶段隔离会话，并拒绝显式状态链接。[OpenCode官方说明](https://github.com/anomalyco/opencode/blob/dev/packages/web/src/content/docs/go.mdx)
4. 新增AGENTS.md，规定不得查看参考答案来设计生产规则，不得根据答案改写原题、筛选成功题或将已用回归集重新称为盲测。旧工具须先满足同样隔离边界才能用于新的验证。
