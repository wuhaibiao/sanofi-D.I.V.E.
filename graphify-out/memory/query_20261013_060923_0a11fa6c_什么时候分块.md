# Q: 什么时候分块

## Answer

当前代码与部署模板在写入抽取时按对话长度分块。extract_chunk_tokens=3500，budget_mode=utf8，所以实际为3500字节，角色和轮次标签也占预算。完整轮次尽量拼在同一块；多轮合计超标开启新块，单轮超标先拆该轮。每个正常抽取块调用一次LLM。输出截断或格式不完整且块内有多个部分时，会对半拆开重抽；单部分仍失败则排队补抽。Embedding按说话人另外分段，目前预算384字节，不增加生成式LLM调用。相关旧记忆受上下文预算裁剪，不独立调用抽取LLM。何时触发批量处理由接入方式决定，宿主适配器或代理按默认24条消息即约12轮触发，REST显式结束会话也触发后台处理。没有修改配置、运行评测或真实模型。Graph Writer source_location memsys/write.py:L266为旧图定位，当前分块代码已直接核对src/memsys/write.py、budget.py、indexing.py和core/serve触发路径。
