Retrieval query LLM yields queries/keywords/time/focus/needs-all plan; exact normalized vector dot products and FTS5 BM25 are fused by a similarity-weighted RRF, source expansion and time/state/confidence weights; local bge-reranker-v2-m3 jointly scores question/document pairs; budget selection renders context/items/trace for the host LLM. Current budget_mode utf8, so context limits are byte units. config/llm/discover manage purpose-specific models/adapters/fallbacks. Current role aliases now GPT-6-Luna for extract/resolve and GPT-6-Luna-read-medium for query/memory/chat; do not repeat old LongCat/Step README settings as current. State distinctions: sessions open -> closed, incremental flush advances turns_done while leaving session open; episodes active/skipped on consolidation, active -> archived, and forgotten/withheld on explicit forget paths; facts current -> superseded when replaced and both current/superseded can archive, explicit forget -> forgotten; uncertain is a boolean/confidence annotation, not a status enum. Forgotten sources are redacted when unambiguous spans allow it, otherwise shared originals are withheld; raw audit data is not automatically physically removed. Extract failure/unavailable -> persisted backlog -> backfill/rebuild -> success removes queue entry; resolver malformed output conservatively retains facts as new. Lifecycle retention uses importance, recency and usage, archives remain eligible for history/complete/fallback queries, and reindex changes derived retrieval data rather than reextracting all originals.
