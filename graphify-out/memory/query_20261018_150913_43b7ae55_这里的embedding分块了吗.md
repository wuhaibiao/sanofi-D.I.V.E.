# Q: 这里的embedding分块了吗

## Answer

Embedding分路径：1事实不二次分块，Writer._embed把每条fact_text(f)作为一个字符串编码，正文含必要完整value、明确事件状态和grounded关系；2会话原文按轮次的User/Assistant角色分别编码，在indexing.episode_index中先按2000字符外层划片，再用counter.split在384预算减角色标签和余量的范围内无损分段。当前计数器单位是UTF8字节，不能称384个BGE token；优先段落/换行/空格，连续无重叠，角色正文所有段拼回原文，存role/start/end和chunk向量。3抽取前检索相关旧事实时整批会话直接一个查询向量不分块；普通检索也是每条query直接一向量。BGEEmbedding输入实际tokenizer核验8192，超限报错不自动截断/分块。批量多个字符串不等于将一条事实分块。LLM抽取仍整批，区别于原文向量分段。
