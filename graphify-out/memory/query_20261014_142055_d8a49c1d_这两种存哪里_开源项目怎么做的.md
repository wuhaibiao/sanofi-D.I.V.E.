# Q: 这两种存哪里，开源项目怎么做的，

## Answer

Expanded from original query via vocab: Store Fact Episode Qdrant. Existing graph supplied navigation only; current store.py, live configuration and current official open-source code ground this answer.

当前项目在线主存储是本机Qdrant，地址http://127.0.0.1:6333，collection_prefix=memsys，namespace=local。原始消息作为kind=turn，逐轮原文作为kind=episode，结构化事实作为kind=fact，都在memsys_records的JSON payload内，按tenant隔离。词法索引在memsys_lexical，1024维稠密索引在memsys_dense_1024；索引可包含事实和轮次对象，默认facts读取不检索原文。实际本机数据路径为/Users/OleniusBlanc227/Library/Application Support/memsys/qdrant/storage/，快照另在qdrant/snapshots。当前在线数据不是仓库内历史评测SQLite文件。

按本次查询的开源实现：
Mem0 OSS当前Python主分支：事实文本与metadata连同embedding写入配置的vector_store payload；SQLiteManager保存记忆变更历史和一个有限的输入消息缓冲，每个session_scope只保留最近10条，完整会话需应用自行归档。infer=False可将输入内容直接作为记忆，默认infer=True是提取事实。官方概览也覆盖托管平台，不能把其SQL源库描述直接当作当前OSS的代码实现。
Sources: https://github.com/mem0ai/mem0/blob/main/mem0/memory/main.py ; https://github.com/mem0ai/mem0/blob/main/mem0/memory/storage.py ; https://github.com/mem0ai/mem0/blob/main/docs/core-concepts/how-it-works.mdx
Graphiti：原始输入以episode节点存图数据库，默认store_raw_episode_content=True，可关闭保存原文；实体节点和关系边是提取的语义结构，事实可追溯episode。默认驱动Neo4j，并可配置其他图驱动。这里指getzep/graphiti开源引擎，不将托管Zep等同于开源内部实现。
Sources: https://github.com/getzep/graphiti ; https://github.com/getzep/graphiti/blob/main/graphiti_core/graphiti.py
Letta当前活跃实现已迁至letta-ai/letta-code。其本地模式以messages.jsonl保存消息/压缩事件记录，以Git支持的MemFS文件和memory blocks管理长期记忆，不要求将每条知识变为SPO事实。system/记忆编入系统提示，其他文件按需读取。旧Letta V1/PostgreSQL方案在archive分支，不能描述成当前所有Letta默认存储。
Sources: https://github.com/letta-ai/letta ; https://github.com/letta-ai/letta-code/blob/main/src/backend/local/local-transcript.ts ; https://docs.letta.com/agent-sdk/memory

你的系统采用原文底档加结构化事实、物理统一Qdrant；保留原文用于溯源与重建，默认答题通过事实读路径。是否保存原文与是否给回答LLM原文是独立的存储和读取选择。此轮仅查询，没有迁移或修改系统。
