# Q: 用户的查询也是用BGE向量化吗

## Answer

是的。当前本地部署中，用户查询也使用 BGE-M3 向量化，和记忆写入共用同一个 embedding 模型。
流程是：入库时把事实文本转成向量存进 Qdrant；查询时把经过查询规划的检索文本也转成向量，再做相似度检索，并结合词法检索；随后由 BGE 重排模型为“问题＋候选事实”打相关性分数，筛选后交给回答模型。
需要区分 BGE-M3（向量化）和 BAAI/bge-reranker-v2-m3（重排打分）。当前源码 read.py:301 调用 models.embedder.embed(plan.queries,purpose="embed_query")；write.py:545 使用同一个 embedder。查询向量化本身不会把问题作为长期事实写入。
