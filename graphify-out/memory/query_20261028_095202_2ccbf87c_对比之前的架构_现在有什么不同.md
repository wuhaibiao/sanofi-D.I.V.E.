Compared with the immediately preceding audit-free architecture, the store, Qdrant hybrid retrieval, BGE reranking and direct host answer remain. Previously ranked evidence was packed by fact limits and context budget. The opt-in semantic path adds bounded exact task-link expansion for advice, then at most one LLM call selecting existing fact IDs without rewriting facts or generating the answer, then full-fact packing in selected priority order. Only selected facts omitted by packing trigger expansion; semantic filtering alone no longer expands the whole pool. Source IDs, recording time, event time, stored validity and optional decision states are rendered distinctly; explicitly selected historical assertions are preserved instead of silently replaced with latest values. Conflicting event-status annotations are retained with field origins and uncertainty rather than rejecting the fact. Selector format, invalid-ID, timeout and transport failures salvage valid IDs or fall back to bounded ranked facts. No answer audit, evidence envelope or original-conversation answering fallback was added. Uncertainty metadata affects the answer prompt but does not gate delivery, and can contribute to overly conservative generation. Selection remains bounded by 128 candidates and runtime 65536 UTF-8-byte units, not unlimited model tokens. Defaults remain ranked and production was not changed; semantic was enabled only in the experiment configuration. The 20-question exposed regression delivered all answers and reduced mean memory bytes 67%, but raw score was 18/20 versus prior19/20 with a suspected false-positive improvement; task expansion triggered zero times.
