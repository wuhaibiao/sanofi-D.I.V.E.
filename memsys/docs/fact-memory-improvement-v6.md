# 事实记忆改进 V6：实施计划

本轮依据通用记忆服务要求实施，不读取公开评测题、参考答案或逐题失败记录来设计规则。保留单批单次抽取、仅事实召回、宿主单次回答及现有追加存储。

| 阶段 | 措施 | 验收条件 |
|---|---|---|
| 结构压缩 | 同轮模型结构已精确保留字面列表/表格时，不再新增重复回补；读取时重复结构值用事实引用共享 | 保留顺序、完整值、事实编号、条件与来源；上下文比逐条重复展示更短；覆盖不明确时不合并 |
| 时间与状态 | 保留显式事件状态，区分事件日期、记录日期、相对时间；分页和HTTP提供相同字段 | 计划/完成/取消不同状态不去重；日期未知不推断发生日；相对表达以记录日期为锚 |
| 用户事实利用 | 建议操作在已召回候选中优先选择用户事实；上下文标明记忆类别 | 紧预算仍保留相关用户约束；普通查询排序策略保持原语义；不增加新候选或来源原文 |
| 验证与部署 | 自编功能场景、相关回归测试、隔离真实模型流程、升级索引及重载本机API | 正常每批一次抽取、每问一次回答；历史原文和已存事实保留；写入和答题调用无公开评测答案 |

自编真实场景在修改代码前保存在 `tests/fixtures/fact_memory_v6_synthetic.json`；校准流程、事件状态与声音记录约束用于功能检查，不能据其通过率声称公开评测准确率或泛化能力。真实验证计划为3个场景，每场景正常一次抽取和一次回答，不调用评分LLM，不读取LongMemEval样本。

现有向量索引若因事实内容格式变更需要升级，只从已存事实和安全原文重建向量，不重新抽取私人历史。临时测试使用独立Qdrant命名空间，完成后清理。

## 执行结果

三项改造已实施。145项相关功能与隔离测试通过；真实自编场景首轮有一条回答截断，且事件状态被模型放在事件值内。修复通用字段兼容及回答完整性后，在新目录完整复核同样三个场景，三条回答均正常完成；首轮记录保持原样。每轮3次抽取、3次回答，没有评分LLM或公开评测回放。

自编校准场景省去一份重复结构；计划/完成场景保留了明确状态；声音记录建议采用了已拥有设备和工作空间限制。但该隐式建议被意图层识别为lookup，因此本场景没有验证建议优先排序，该策略由自编预算边界测试验证。功能通过不能估计泛化正确率。上线、原始记录指纹及详细观察见 [V6实施报告](../runs/fact-memory-v6-20261014/report.md)。
