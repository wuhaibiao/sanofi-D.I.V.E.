## 结果复核

三项原始标签回退：一项写入阶段的服务方 HTTP 400 / invalid_prompt，一项时间推理错误，一项个性化建议判分回退。另有一项旧错继续未通过。

写入失败的题目没有进入返回渲染或模型答题。服务方拒绝了一个历史会话；评测入口随后因历史未处理完整而停止该题回答。这是服务拒绝与现有交付门槛共同形成的失败链，不能归因于返回格式，也不能从总成绩中排除。

时间题的实际提示同时保留了已完成的过去行程和未来计划。答案使用未来计划计算预订距今时间，表现为事件对应和时间线选择错误；必要的过去行程并未在返回层丢失。日志不足以证明是规则改写、重新抽取的差异还是生成随机性导致，不能单独归因。

晚间建议题的新回答仍包含个人时间约束、减少刷屏的目标和曾讨论的练习，并非完全没有个性化。与旧答案文本表现接近，一次原始判分不足以确认通用化回退；保留错误标签，不进行重复评分或人工改标。

共同正常交付的19题仅用于token与耗时对照，全部失败仍计入20题准确率和交付率。返回正文与规则的字节对照固定了本轮相同的选中事实；跨历史运行的实际token还受重新抽取差异影响。

观察到的远端回答耗时明显下降，不能由4.38%的输入token下降直接解释；没有TTFT、排队与分段网络计时，不能承诺这是返回层带来的速度收益。

本轮未达到替换主干的标准。保留实验分支和全部原始结果，不合并、不部署。
