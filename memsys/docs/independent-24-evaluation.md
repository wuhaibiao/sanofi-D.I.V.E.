# 独立24题验收方案

用户最新要求为六类能力各4题。原 LongMemEval 的500题全部已参与项目执行或调试，不能再从中抽出独立新题。末组使用新的公开语料，保留六类能力与24题规模；选择与适配方案先固定，两个开发组通过后再冻结题目并执行。

| 模块 | 题数 | 来源 |
| --- | ---: | --- |
| 跨会话关系推理 | 4 | ConvoMem implicit connections，3段证据会话 |
| 信息更新 | 4 | ConvoMem changing facts，3段证据会话 |
| 用户事实 | 4 | ConvoMem user facts，3段证据会话 |
| 助手事实 | 4 | ConvoMem assistant facts，3段证据会话 |
| 偏好 | 4 | ConvoMem preferences，2段证据会话 |
| 时间推理 | 4 | LoCoMo temporal，完整发布会话 |

ConvoMem 的证据会话模式对应本项目原来的 LongMemEval Oracle 模式：提供所选任务完整原始会话，不提供标记过的答案片段。ConvoMem 提供不同证据类别和混合干扰会话的多种规模，见[发布者的数据与代码说明](https://github.com/SalesforceAIResearch/ConvoMem)。本末组是跨数据集的独立诊断样本，不能称为标准 ConvoMem 全量分数。

LoCoMo 发布两个具名人类参与者的会话、原始时间戳、可用图像说明及独立问答标注，见[发布者说明](https://github.com/snap-research/locomo)。导入时每个会话作为用户提供的完整人类对话记录，保留说话者姓名和全部发布文本；保留发布的图像说明，不抓取外部图片。没有把一个人类参与者改成AI助手。原始会话时间戳保持不变。末组采用既定Boolean评分，不称为 LoCoMo 官方F1分数。

## 固定选择与来源边界

选择种子固定为 `independent-modules-four-20261012`，只用模块、文件路径、记录序号和类别元数据选题；不检查参考答案、运行正确率、写入完成率或耗时。ConvoMem的20题来自不同persona文件，每文件随机选一个记录。模式校准文件对应的persona排除；LoCoMo模式校准用的首个会话排除，四道时间题从四个不同的其余会话中选取。

原始文件必须保存发布版本号、下载URL和SHA-256。ConvoMem固定版本为 `e3e9b39115b02346824c70d349350de738f8be41`；LoCoMo版本及校验值已保存于本轮研究目录，最终选择清单还会一起冻结。原始标注封存于下载文件和评测数据文件中；既有白名单加载器分离参考答案，记忆写入只接收原始会话、角色和会话时钟。

ConvoMem没有发布原始会话时间戳。适配器使用固定的导入顺序时钟，且每条原文均明确标出“记录时钟是导入顺序，不是原始事件日期”。不能据此补造原始事件日期。时间推理模块因此采用有实际发布会话日期的LoCoMo。

`message_evidences`、`containsEvidence`、`scenario_description`、persona描述、来源模型名、`evidence`、事件标注、观察及预制摘要均不传入记忆系统。参考答案只在24个回答全部完成后进入评分器。两项适配保护测试验证这些标注与评分答案不会出现在原始会话输入中，同时保留完整原话、角色或具名人类说话者、时间戳及发布图像说明。

## 判定

同一冻结源码、配置和语言模型、并发1；实际写入后检查原始文本、角色、日期及抽取/索引覆盖，再读取及评分。每题读取180秒，共享重试预算；批次读取最多60分钟。每批至少23/24，逐模块报告0至4的正确数，原始Boolean标签不改写。最后的24题在项目中未参与调试；公开模型是否在预训练中接触过公开语料无法由本次验收证明。

第一次独立验收若未达标，保留原始结果；参与错误分析的题此后标为开发样本，下一次独立验收从未用过的来源记录重新冻结24题。不能反复生成或更换标签来让同一份输出达标。


执行脚本 `scripts/prepare_independent24.py` 在选题与下载前核验两组各模块4题、24个完整回答、24个原始Boolean标签、至少23个True、冻结版本及原始来源覆盖。两个开发组必须使用同一源码和模型配置。未通过时停止，不能用新题替代失败的固定组。
