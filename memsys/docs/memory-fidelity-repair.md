## 实现

- 单次抽取仍返回既有命名事实对象。抽取单位从整段摘要明确为可复用的独立陈述；同一对象的完整属性可用紧凑值对象保存。用户目标独立于助手提供的做法，不用宽泛兴趣代替具体任务。没有新增第二次抽取、语义裁判或事实补写模型。
- 建议类查询沿用已检索候选中的用户事实优先策略，最终渲染也保持这一顺序；用户上下文和助手信息分别按原有日期顺序排列，每条事实及值只呈现一次。普通回忆仍保持全局日期顺序。试装和最终裁剪使用同一种呈现格式计算预算。
- 适用于宿主的记忆使用规则要求建议推进已知任务，并简短说明具体联系。助手旧建议可提供方法，但不证明用户已经采纳、购买或完成。未知或多个可能任务保留条件或提出一个明确问题。规则随实际 `recall.context` 进入 WebChat 的第一次回答，不依赖旧的原文读取或回答复核支路。
- 覆盖报告增加 `accounting_basis=fact_source_links_only` 和 `content_completeness_verified=false`，明确源关联检查的证明范围。它不验证每个具体细节是否保全，也不阻止写入或回答。证据审计继续仅作诊断，不改写答案。
